# Docs

This directory keeps the project-defining decisions inside the repository so
they do not only live in `~/.gstack`.

## Core docs

- `architecture/server.md` - approved single-node server design and scaling seams
- `architecture/source-layout.md` - the current repo structure and what each area owns
- `product/identity.md` - project identity, license posture, and hard non-goals
- `product/day-1-hand-analysis.md` - the first analysis feature and its scope
